# Event Valley – College Event Management System

Event Valley is a web-based college event management system designed to
streamline event creation, approval, registration, and participation.

## Features

- Role-based access for Students, Organizers, and Faculty Coordinators
- Event creation and management
- Faculty event approval/rejection
- Organizer account approval
- Student event registration
- Event filtering and upcoming-event listing
- Registration validation and duplicate-registration prevention
- Notifications
- Participant and event management

## Technologies

- HTML
- CSS
- JavaScript
- NeDB / Local database

## User Roles

### Student
- Browse upcoming events
- Register for events
- View registered events
- Request organizer access
- Receive notifications

### Organizer
- Create events
- Edit events
- Manage their events
- View registrations

### Faculty Coordinator
- Approve/reject events
- Approve organizer requests
- Monitor event activity

## Project Structure

- `css/` – Stylesheets
- `js/` – JavaScript functionality
- `pages/` – Role-specific pages
- `RMMM/` – Project documentation and testing artifacts
- `landing.html` – Landing page
- `login.html` – Login page
- `signup.html` – Signup page
